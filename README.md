## 1. 이야기 노래 스튜디오

마사지를 해드리며 나누는 어르신과의 대화를 실시간으로 받아 적고, AI가 그 인생 이야기로 맞춤 가사를 지어 Suno(AI 작곡)로 연결하는 모바일 웹앱.

**흐름**: 어르신 성함·곡 분위기(찬양/신나는 트로트/잔잔한 트로트/발라드)·보컬(여성/남성/아이/가족) 선택 → 녹음(실시간 받아쓰기 + 봉사자용 질문 가이드 6종 순환) → Claude가 요약·가사·Suno 스타일 프롬프트 생성 → 복사해서 Suno에 붙여넣기 → 완성곡 링크로 QR 생성(포토카드용)

**기술 포인트**
- Web Speech API(ko-KR) 실시간 인식 + 안드로이드 중복 전송 버그를 잡는 겹침 병합(`mergeFinal`) 알고리즘
- 카카오톡 인앱 브라우저 감지 → "크롬으로 열기" 원터치 안내
- Vercel 서버리스(`api/generate.js`)가 Anthropic API를 프록시: API 키는 서버에만, 팀원은 **팀 코드** 하나로 인증
- 스타일 프롬프트는 AI가 아니라 코드의 `MOODS` 맵에서 확정 생성 (장르 혼입 방지)
- 음성 인식 불가 환경용 텍스트 직접 입력 폴백 내장

**환경변수 (Vercel)**: `ANTHROPIC_API_KEY`, `TEAM_CODE`

## 2. 말씀 사진관

태블릿 키오스크에서 사진을 찍으면 성경 말씀과 합성해 감열 프린터로 즉석 인쇄. 선교팀이 떠난 뒤에도 교회가 매주 운영하는 것이 목표.

**흐름**: 성함(호칭 포함, 선택) 입력 → 페이지 내 카메라(전면/후면 전환, 3초 타이머) → 사진+말씀 카드 자동 합성 → 다른 말씀 뽑기(말씀 풀 100개) → 블루투스 인쇄 또는 PNG 저장

**기술 포인트**
- Web Bluetooth로 고양이 프린터 계열(GB01/02/03, GT01, YT01, MX05~10, **SC05 확인됨**) 직접 제어 — 앱 불필요
- 프로토콜: `0x51 0x78` 프레임 + CRC8, 384px 행 단위 비트맵(LSB 우선), 에너지/급지 제어
- 사진 파이프라인: **지역 적응 명암 보정(조명 맵 기반, 역광에서도 얼굴 살림) → 언샤프 마스크 선명화 → 플로이드-스타인버그 디더링**
- 한글 웹폰트 서브셋 문제 해결: 인쇄할 실제 문장을 `document.fonts.load()`에 넘겨 필요한 글자 조각까지 로드
- 설정(⚙): 교회명·하단 문구·진하기·밝기·선명도, 진단 도구(테스트 인쇄/용지 이송/방식 B/로그 토글)

**요구 환경**: 안드로이드 + 크롬 (iOS는 Web Bluetooth 미지원)

## 삽질 기록 (Troubleshooting Log)

실전 배포까지 겪은 문제와 해결. 같은 걸 만들 다음 사람을 위해 남긴다.

| # | 증상 | 원인 | 해결 |
|---|---|---|---|
| 1 | 팀원 20명에게 API 키 배포 불가 | 정적 페이지 구조 | Vercel 서버리스 프록시 + 팀 코드 인증으로 전환 |
| 2 | 카톡에서 마이크 권한창 무한 반복 | 카톡 인앱 브라우저가 권한 미저장 | 인앱 감지 배너 + `kakaotalk://web/openExternal` 원터치 크롬 열기 |
| 3 | 모바일에서 받아쓰기 먹통 | SpeechRecognition ↔ MediaRecorder 마이크 충돌 | 모바일은 받아쓰기 전용(녹음 백업 비활성) |
| 4 | 같은 문장이 점점 길어지며 반복 기록 | 안드로이드 크롬이 확정 결과를 누적 재전송 | 꼬리-머리 겹침을 찾아 병합하는 `mergeFinal()` + 짧은 세션 재시작 모드 |
| 5 | 찬양 선택인데 스타일에 "Korean trot" | 스타일 작성을 AI 재량에 맡김 | 분위기×보컬 확정 템플릿(`MOODS`)으로 코드 이관 |
| 6 | 프린터 연결됐는데 출력 안 됨 | (프로토콜 의심했으나) 감열지 방향 반대 | 용지 재장착. 진단용 급지 테스트/로그 기능은 이때 탄생 |
| 7 | SC05-A64B 미지원 모델 우려 | 고양이 프린터 변종 | 동일 서비스(0xAE30) 확인, 표준 방식 A로 정상 작동 |
| 8 | 찢을 때 하단 문구 잘림 | 하단 여백 부족 | 상단 여백을 하단으로 이전 + 인쇄 후 배출 96→128줄 |
| 9 | 태블릿에서 전면 카메라 전환 불가 | 카메라 앱이 `capture` 속성을 엄격 적용 | getUserMedia 기반 페이지 내 카메라로 전환 (전면/후면/타이머/폴백) |
| 10 | 말씀 글자 일부 깨짐 | 한글 웹폰트 서브셋 미로드 (캔버스는 자동 로드 안 됨) | 실제 인쇄 문장을 `fonts.load()`에 전달 |
| 11 | 역광에서 얼굴이 검게 인쇄 | 전역 평균 기반 보정의 한계 | v1 전역 → v2 중앙 가중 → **v3 지역 적응(조명 맵)** 3차 개선 |
| 12 | 사진이 흐릿함 | 태블릿 카메라 + 200dpi 감열 한계 | 언샤프 마스크 선명화 단계 추가 (⚙ 슬라이더) |

**하드웨어 구매 교훈**: 겉모양이 같아도 칩셋이 다르다. 브랜드 제품(PeriPage/Paperang)이 오히려 독자 프로토콜로 비호환, 영수증형(PT-210 등)은 블루투스 클래식이라 Web Bluetooth 연결 자체가 불가. 구매 전 판매자에게 "블루투스 페어링 시 기기 이름"을 물어볼 것.

## 운영 가이드 (교회 비치용)

1. 태블릿 크롬에서 `/print.html` 열기 → 메뉴 → **홈 화면에 추가** (전체화면 키오스크)
2. 프린터 전원 켜고 [🖨 인쇄하기] → 기기 선택 (한 번 연결하면 유지)
3. 평소 관리: **프린터·태블릿 충전, 감열지 롤 교체(인쇄면 방향 주의!)** — 이 두 가지가 전부
4. 인쇄가 갑자기 안 되면: 프린터 전원 버튼으로 절전 해제 → 다시 [인쇄하기]
5. 촬영 원칙: **찍히는 분이 밝은 쪽(창문·조명)을 바라보게**
6. 문구 변경: ⚙에서 교회명·하단 문구 수정 (기기별 저장)

## 🚀 우리 교회/모임에도 설치하기 (5분)

**말씀 사진관은 서버·계정·비용이 전혀 필요 없습니다.** 가장 쉬운 방법부터:

### 방법 1 — 그냥 이 주소를 쓰세요 (개발 지식 0)
1. 안드로이드 태블릿/폰의 **크롬**에서 https://onmaeum-song-studio.vercel.app/print.html 열기
2. ⚙ 설정에서 **교회명·하단 문구를 우리 것으로 변경** — 설정은 기기별로 저장되므로 같은 주소를 써도 다른 곳과 절대 섞이지 않습니다 (사진·갤러리도 전부 그 기기 안에만 저장, 서버 전송 없음)
3. 메뉴 → **홈 화면에 추가** 하면 키오스크 완성

### 방법 2 — 내 것으로 포크해서 커스터마이즈
1. 이 레포 **Fork** → `print.html` 하나가 사진관 전부입니다 (단일 파일, 빌드 없음)
2. GitHub Pages 또는 Vercel에 무료 배포 (기본 문구·말씀 풀·디자인을 코드에서 수정 가능)
3. 노래 스튜디오(`index.html`)까지 쓰려면 Vercel 환경변수 `ANTHROPIC_API_KEY`가 필요하지만, **사진관(`print.html`)은 키 없이 완전 동작**합니다

### 준비물 (총 2~3만원대)
| 품목 | 비고 |
|---|---|
| 감열 프린터 | "고양이 프린터"로 검색 — GB/GT/YT/MX/SC 계열 (SC05 실사용 검증) |
| 감열지 롤 | 57mm 폭. 오래 보관하려면 **고보존(long-life) 감열지** 권장 |
| 안드로이드 기기 | 크롬 필수 (iOS는 Web Bluetooth 미지원으로 인쇄 불가, 저장·공유는 가능) |

> 회사 로비용으로 콘텐츠만 바꾼 **굿모닝라이언 행운 사진관** 변형도 있습니다 — 같은 엔진에서 `tools/build_lion.py`로 생성. [체험하기](https://baezzanglion.github.io/sponge-intro/lion.html)
